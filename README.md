# Лабораторная работа №2 по ОС

**Вариант 12. Юрин Матвей Юрьевич, М8О-206БВ-25.**

Родитель читает строку, первый ребёнок переводит буквы в верхний регистр, второй оставляет один обычный пробел вместо нескольких. Готовая строка возвращается родителю.

```text
parent → pipe1 → child1 → pipe2 → child2 → pipe3 → parent
```

Строки читаются через `getline`, поэтому фиксированного ограничения в 1024 символа нет. Буфер увеличивается по мере необходимости. Программы рассчитаны на POSIX/Linux; тесты также прошли на macOS.

## Файлы

- `program/` — три исходника C и файл сборки.
- `report/Лабораторная_2_Юрин.docx` — отчёт в стиле предыдущей лабораторной.
- `report/Лабораторная_2_Юрин.pdf` — готовый PDF.
- `report/Защита.md` — объяснения, ответы на вопросы и короткая шпаргалка.
- `results/` — реальные результаты macOS и Ubuntu, трассировка и проверка памяти.

## Сборка и запуск

Из корня проекта:

```bash
make
cd program
./parent
```

Ввести строку, например `hello     my   friend`. Результат — `HELLO MY FRIEND`. Для завершения ввода нажать Ctrl+D на пустой строке.

Родитель запускается из папки `program`: там должны находиться исполняемые `child1` и `child2`.

В Ubuntu можно собрать с GCC:

```bash
make CC=gcc
```

Или отдельно из `program`:

```bash
gcc -Wall -Wextra -Wpedantic -std=c11 -D_POSIX_C_SOURCE=200809L child1.c -o child1
gcc -Wall -Wextra -Wpedantic -std=c11 -D_POSIX_C_SOURCE=200809L child2.c -o child2
gcc -Wall -Wextra -Wpedantic -std=c11 -D_POSIX_C_SOURCE=200809L parent.c -o parent
```

## Проверка

Программа уже проверена на macOS и Ubuntu. В папке `results` сохранены результаты 13 проверок: обычные и пустые строки, несколько строк подряд, повторные пробелы, табуляции, EOF и длинные строки — 5000 и 200001 байт до переноса строки. Отдельно проверялись отсутствие дочерних программ, получение ответа до EOF и ошибка вывода в Linux.

Файлы автотестов удалены. Сохранённые результаты находятся в `results/tests-macos.json`, `results/tests-linux.json` и `results/errors-*.json`.

Простая ручная проверка из папки `program`:

```bash
printf 'hello     my   friend\n' | ./parent
```

Ожидаемый результат: `HELLO MY FRIEND`.

Реальная трассировка получена в Ubuntu в UTM. Повторный запуск из `program`:

```bash
strace -f -o ../results/trace.txt ./parent < ../results/trace-input.txt > ../results/trace-output.txt
```

`-f` позволяет увидеть родителя и обоих детей. В отчёте использован сохранённый фрагмент `results/trace-fragment.txt`.

Удалить собранные программы:

```bash
make clean
```
